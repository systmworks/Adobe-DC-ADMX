# Contributors

A huge thank you to everyone listed below.

This template is considerably better than it would have been on its own. Nearly every entry in the changelog traces back to somebody taking the time to open an issue, test a setting against their own estate, or send a pull request - correcting registry paths, surfacing settings Adobe documents only in scattered knowledge base articles, catching scoping mistakes, and finding plain bugs. None of these people were obliged to help, and the template is more accurate and more useful because they did.

If you spot something wrong or missing, please open an issue or a pull request. You will end up on this list too.
